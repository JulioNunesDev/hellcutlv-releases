# HELLCUTLV — downloads

Instaladores e avisos de versão do **HELLCUTLV** (cortes automáticos de lives).

- **Baixar:** veja a página [Releases](../../releases/latest).
- `latest.json` — versão mais nova (o programa avisa quando sai uma).
- `revogadas.json` — chaves desativadas (o programa confere 1x por dia).

Comprou e perdeu a chave? Pegue de novo na página "Minha chave" (link no e-mail da compra).
